# Stephania Pérez | Design tokens

## Brand

- **Primary**: `#0A0A0A` (text, buttons)
- **Background**: `#FFFFFF`
- **Muted text**: `#6B6B6B`
- **Borders**: `#D4D4D4`
- **Accent (CTA)**: `#2C3440` (slate)

## Typography

- **Titles / headings / `.font-serif`**: Minerva Modern (self-hosted)
- **Body, nav, forms**: Raleway (Google Fonts)
- Nav: uppercase, letter-spacing ~0.2em, 11–12px
- Section titles: serif, uppercase, centered

## Layout

- Max content width for form: ~720px centered
- Header: logo centered; nav split left/right on desktop; stack on mobile
- Generous vertical rhythm (py-16–24 between sections)
- Hero: full viewport (`min-h-svh`), nav overlay transparente, CTA ghost (borde blanco) centrado abajo

## Form

- Thin 1px borders, no heavy shadows
- Floating labels on focus/filled
- Full-width submit, dark accent background
- Checkbox: minimal square with thin border

## Imagery

- High-quality interior photography; let color come from photos
- UI stays neutral (white/black/gray)
